Quick CSS Override to Restore Clean Readability

If you want to make these saved HTML snapshots readable without re-running your capture script, you can override the inline styles in <head> (or via a quick snippet/style rule) to flatten the chrome and normalize typography:

CSS
<style id="snapshot-clean-override">
  html, body {
    max-width: 100% !important;
    overflow-x: clip !important;
    background: #fff !important;
    color: #111 !important;
    font: 14px/1.55 system-ui, -apple-system, "Segoe UI", sans-serif !important;
  }
  body {
    margin: 24px auto !important;
    max-width: 820px !important;
    padding: 0 16px !important;
  }
  /* Normalize inline fonts & flex/grid sidebar quirks */
  #app-root, #app-root * {
    font-family: system-ui, -apple-system, "Segoe UI", sans-serif !important;
    box-sizing: border-box !important;
    max-width: 100% !important;
  }
  code, pre, kbd, samp {
    font-family: ui-monospace, SFMono-Regular, Consolas, monospace !important;
  }
  /* Hide noisy icon ligature text if font is unavailable */
  mat-icon.lumi-symbols,
  .mat-mdc-button-touch-target,
  .mat-focus-indicator,
  .mat-mdc-button-persistent-ripple {
    display: none !important;
  }
  /* Make nav/chat items clean vertical links instead of cramped flex pills */
  mat-nav-list,
  conversations-list {
    display: flex !important;
    flex-direction: column !important;
    gap: 4px !important;
    width: 100% !important;
    padding: 0 !important;
    margin: 0 !important;
  }
  a.mat-mdc-list-item,
  button.mat-mdc-list-item {
    display: flex !important;
    align-items: center !important;
    justify-content: flex-start !important;
    width: 100% !important;
    height: auto !important;
    min-height: 0 !important;
    padding: 6px 10px !important;
    margin: 0 !important;
    border-radius: 6px !important;
    text-align: left !important;
    text-decoration: none !important;
  }
  .title-text {
    font-size: 13.5px !important;
    line-height: 1.4 !important;
  }
</style>
